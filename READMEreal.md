# SG24MM

This is just a bunch of information about the Mod Manager if your curious or need help with it. 
Anyways Have fun I guess?

**SG24MM** is an unofficial mod manager designed specifically for **Sonic X Shadow Generations (2024)**.

## Features

* Import Sonic X Shadow Generations mods
* Support for ZIP and extracted mod folders
* Enable and disable mods
* Automatic backup and restoration of original game files
* Installation safety checks
* Mod conflict detection
* Duplicate mod protection
* Mod descriptions
* Mod search
* Game folder validation
* Launch the game directly from SG24MM

## Requirements

* Windows 11 
* Sonic X Shadow Generations (2024[Steam])

## Installation

1. Download the latest SG24MM release.
2. Extract the downloaded ZIP.
3. Open the extracted folder.
4. Run `SG24MM.exe`.
5. Open **Settings** and select your Sonic X Shadow Generations game folder.
6. Import your mods and manage them through SG24MM.

## Mod Safety

SG24MM includes safety checks designed to reduce the risk of accidentally overwriting original game files.

The application can create backups before installing mods and can restore those files when a mod is disabled.

SG24MM also checks for conflicting active mods and unsafe installation states.

Modding can still cause unexpected behavior, so users should maintain their own backups of important files.

## Supported Game

SG24MM is designed specifically for:

**Sonic X Shadow Generations (2024)**

It will NOT work on other Sonic games or the 2011 release of Sonic Generations
